**视觉风格**: 生物发光赛博朋克 (Bioluminescent Cybernetics)  
**核心理念**: 神经触须主动牵引协议 —— 记忆不是被动存储，而是主动寻求用户

## 🎨 视觉元素

| 元素 | 描述 | 色彩 |
|------|------|------|
| **核心 (Void Core)** | 平静的虚空核心，代表用户当前焦点 | 深空黑 |
| **神经触须 (Memory Vines)** | 有机记忆触手，主动向内延伸 | 电青→霓虹橙渐变 |
| **记忆节点 (Memory Pods)** | 休眠/激活状态 | 暗金/亮橙 |
| **数据粒子 (Data Particles)** | 快速移动的光斑条纹 | 霓虹橙/青色 |

## 🚀 三步执行流程

### 第一步：定风格
- 使用 `prompts/01-concept.md` 生成 4 张变体
- 选择最像"发光水母 + 电路板"的图片
- 点击 **Set as Style**

### 第二步：生素材
- 使用 `prompts/02-detail.md` 生成 2 张卡片图
- **留白处理**（AI 文字不准，后期 Figma 加中文）

### 第三步：生大图
- 使用 `prompts/04-workstation.md` 生成主视觉
- 预留标题位置（后期加：`MNEMONIC GROWTH SYSTEM // VER 2.0`）
