# Prompt 01: 数字记忆生态系统概念图

## 用途
主视觉概念图，用于定风格（第一步）

## Prompt 正文

```
A conceptual diagram of a Digital Memory Ecosystem. The style is "Bioluminescent Cybernetics" (glowing blue/orange tendrils on a matte dark gray background).

Visual Logic Rules:
1. Center: A calm, void-like Void Core (representing the user's present focus).
2. Vines: Organic memory tendrils reaching INWARD toward the core. They are NOT roots going out; they are hands reaching in.
3. Strength Indicator: The thicker and brighter the vine, the stronger the memory connection.
4. Color Coding: Dormant memory = Dim Gray/Gold. Activated/Reinforced memory = Electric Cyan to Neon Orange gradient.
5. Background: Pure #121212 with subtle grid lines resembling a circuit board that is overgrown with moss.

Aspect Ratio: 16:9
Style: Vector-like flat illustration with high detail, 8k
```

## Midjourney 参数建议

```
/imagine prompt: [上述内容] --ar 16:9 --v 6.0 --style raw --q 2
```

## 执行步骤

1. 生成 4 张变体 (`--v 6.0`)
2. 选择最像"发光水母 + 电路板"的一张
3. 点击 **Set as Style** 保存风格
4. 后续图片可添加 `--sref [风格链接]` 保持一致性
