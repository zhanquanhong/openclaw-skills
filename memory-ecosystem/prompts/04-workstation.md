# Prompt 04: 共生记忆工作站蓝图

## 用途
主视觉大图，用于第三步生成最终主视觉

## Prompt 正文

```
Master Prompt: A magnificent Symbiotic Memory Workstation Blueprint.

Composition: Wide angle shot of a designer's desk, but the desk is morphing into a living Neural Ecosystem.

- Left Area: Dark, sleeping Memory Pods hanging from an invisible ceiling, slightly dusty, dim bronze glow.
- Right Area: Bright, active Memory Vines that have crawled across the desk and are wrapping gently around the user's stylus/wrist.
- Key Visual Metaphor: The user is NOT digging in drawers. The vines are bringing a glowing gemstone (The Answer) to the user's hand.
- Style: Studio Ghibli's nature detail mixed with the UI of "Ghost in the Shell".
- Mood Lighting: A spotlight of pure white light on the user's hand receiving the memory. Everything else fades to soft shadow.
- Text Integration: Leave a clean dark bar at the very top or bottom for a title.

Style: Bioluminescent Cybernetics, 8k detail, cinematic lighting
```
