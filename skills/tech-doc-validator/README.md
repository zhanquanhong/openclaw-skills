# 技术方案验证器 (tech-doc-validator)

**版本**: v1.0.0  
**技术栈**: JAVA 优先，支持 Python/前端  
**目标**: 让技术方案一目了然，零歧义，AI 可提取

---

## 快速开始

### 飞书使用

```
/validate https://feishu.cn/docx/xxx
```

### 命令行使用

```bash
python -m src.main validate 技术方案.md
```

---

## 核心功能

### 5 个必填项（70 分）
- ✅ 任务类型标记（🆕/🔄/♻️/🗑️/🔗）
- ✅ 依赖关系说明
- ✅ 接口定义完整性
- ✅ 实现说明具体性
- ✅ 验收标准可执行性

### 3 个加分项（30 分）
- ⭐ 工作量评估
- ⭐ 优先级标注
- ⭐ 业务背景

---

## 评分标准

| 分数 | 等级 | 说明 |
|------|------|------|
| 90-100 | 优秀 | 可直接生成 WBS |
| 80-89 | 良好 | 建议修复小问题 |
| 70-79 | 合格 | 可生成 WBS |
| 60-69 | 需改进 | 建议修复后再生成 |
| <60 | 不合格 | 必须修复 |
