# 问题反馈表单模板

> 用于收集团队成员使用 Code Reviewer / Auto Tester 时遇到的问题

**表单链接：** 创建飞书表单后替换
**二维码：** 飞书表单自动生成

---

## 表单问题设计

### 1. 基本信息

**姓名** [填空题]
**部门/小组** [单选题]
  - 后端一组
  - 后端二组
  - 中台组
  - 其他

### 2. 问题分类

**遇到的问题类型** [多选题]
  - [ ] 安装配置问题
  - [ ] IDEA 插件无法识别
  - [ ] 扫描报错/异常
  - [ ] 误报/漏报
  - [ ] 性能问题（扫描太慢）
  - [ ] 功能建议
  - [ ] 其他

### 3. 问题详情

**使用的版本号** [填空题]
  - 提示：运行 `git log -1 --oneline` 查看

**IDEA 版本** [填空题]
  - 例如：IntelliJIdea2024.1

**操作系统** [单选题]
  - Windows 10/11
  - macOS
  - Linux (Ubuntu/CentOS/其他)

**问题描述** [多行填空]
  - 请详细描述遇到的问题
  - 包含操作步骤、错误信息等

**截图/录屏** [上传题]
  - 支持图片、视频上传

**代码示例（可选）** [多行填空]
  - 如果有误报/漏报，请提供代码片段

**联系方式** [填空题]
  - 飞书账号或手机号

### 4. 优先级

**问题紧急程度** [单选题]
  - 🔴 严重 - 无法使用，阻塞工作
  - 🟠 高 - 影响效率，需要尽快修复
  - 🟡 中 - 可以使用，但有不便
  - 🟢 低 - 功能建议，可后续优化

---

## 反馈处理流程

```
用户提交表单
    ↓
飞书自动通知（机器人消息）
    ↓
管理员查看问题
    ↓
分类处理：
  - Bug → 创建 Git Issue
  - 建议 → 加入需求池
  - 咨询 → 直接回复
    ↓
修复后发布新版本
    ↓
通知用户更新
```

---

## 飞书表单创建步骤

1. 打开飞书 → 云文档 → 新建 → 表单
2. 按上述模板添加问题
3. 设置"提交后显示"：感谢语 + 预计处理时间
4. 开启"飞书机器人通知"：提交后自动发送到管理群
5. 生成分享链接和二维码
